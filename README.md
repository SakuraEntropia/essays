一个用来放**零散想法**的仓库。不是教程，不是作品集——**是想到哪儿写到哪儿的地方。**

A collection of loose thoughts. Not tutorials, not a portfolio — just a place to put things down.

## 这个仓库放什么

- **观察**：某个现象的命名与拆解（比如那篇 rage bait）
- **分析**：把"感觉不对"翻译成"结构上哪里不对"
- **笔记**：读书、看片、听音乐时想清楚的东西

不放：代码、项目文档、教程。那些各自有各自的仓库。

## 写作原则

- **区分描述与判决。**尽量说清哪句是事实、哪句是推论；推论标出来，可证伪的写明证伪条件。
- **不许自己豁免。**如果一条标准用来要求别人，它同样适用于本文。
- **不确定就说不知道。**包括：样本不足、只看了转述、没核实原文。

## 几个约定

- **原文优于转述。**引用别人的东西，尽量取回原文；只拿到转述时，只评价那一句的形式，不评价篇章结构。
- **不点名。**涉及具体个人的分析，尽量抽象成现象；必须举实例时，用公开数据，不用隐私。
- **标注状态。**实证、推论、猜测分开写。写错了就在原文上改，不用悄悄删掉。
