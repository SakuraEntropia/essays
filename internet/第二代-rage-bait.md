# 第二代 Rage Bait

> 一份命名文档。目的不是控诉，是**分类**——因为只有被命名的东西才可以被处理。
>
> 本文的所有判断都标注了来源：**已核对原文**的为实证；**推论**的为框架推演，可被证伪。

---

## 0. 一句话定义

> **一代 rage bait 靠"裸露的攻击"获取愤怒；二代靠"有辩护的攻击"获取自我怀疑。**
>
> 一代的攻击是空的，所以它可被识别、可被举报、可被无视。
> 二代的攻击是真的——**它把人身判决装在一个不需要辩护的专业外壳里**，于是受害人面对的不是一个钓鱼的人，**而是一段他没法说"你胡说"的文本。**

---

## 1. 为什么用恐怖片做类比，以及类比到底成立在哪

直觉版本：欧美恐怖给血腥，日式恐怖不给血腥但更吓人。

**更精确的版本：日式恐怖不是"更吓人"，是"更晚离开"。**

| | 欧美恐怖 | 日式恐怖 |
|---|---|---|
| 手段 | jump scare、血浆、惨叫 | 留白，什么都不给你看 |
| 作用时间 | **当场炸，当天忘** | **关掉屏幕之后才开始工作** |
| 让你补完 | 不需要 | **必须**——而你自己补的那版永远比导演拍的狠 |
| 结果 | 被吓到 | **被留下** |

**对应到 rage bait：**

| | 一代 rage bait | 二代 rage bait |
|---|---|---|
| 愤怒的形态 | 当场炸 | **带回家** |
| 结束后 | 你知道那是钓鱼，扔了就完了 | **你对它没有干净的结论可用** |
| 作用对象 | "网上有个人骂人了" | **"这段话说的是我，而且它好像对"** |
| 恢复时间 | 几分钟到一天 | **不确定，可能很久** |

**类比成立的核心：两者的强度差别不在刺激量，在停留时间。**

---

## 2. 真正的分界线：攻击有没有辩护

这是整个框架的支点。

### 2.1 一代的辩护是空的

"我就是说实话""开个玩笑而已""玻璃心别上网"——**这些话谁都听得出是借口**，包括说的人。所以一代的攻击是**裸露的**，识别成本极低。

### 2.2 二代的辩护是实的

二代攻击者的第一个动作，通常是**真的给出正确的技术判断**。

**已核对原文的实例**（一篇针对绘画提问的回答）：

- "色彩必须要基于【黑白关系】……去色之后留下的明度可完全不同" → **正确**
- "黑白关系必须要基于【透视关系】" → **正确**
- **"雨水效果的生态位，被乱糟糟的纹理贴图效果给死死占住了"** → **正确，且是洞见级的画面诊断**
- "画面，是【对比】出来的" → **正确**

**于是攻击被装进了一个不需要辩护的容器。**

### 2.3 由此产生的认知失调（二代独有）

- **一代受害人**：我被冒犯了，但我知道那是钓鱼 → **可以不理。**
- **二代受害人**：我被冒犯了，**可是他说得对啊** → **凭什么不理？**

> **一代的受害者是"被激怒的人"。**
> **二代的受害者是"无法反驳的人"。**

**这是本框架最重要的一条判断。**

---

## 3. 核心机制：载体句

二代最关键的构成是**载体**（carrier）——一段**可核实、专业、正确**的技术内容，它的功能不是帮助，是**取得开火的资格**。

**已核对的真实结构**（同一篇回答）：

| 位置 | 内容 | 类型 | 给了可执行动作吗 |
|---|---|---|---|
| 首句 | "还能说什么呢？挨个解答你的每一个'小问题'吧。什么雨水……什么藏色……**想的真多啊**……" | **资格判决（从第一句就在）** | 无 |
| 1 | "找找【参考】吧，不要在'几乎连门槛都没迈入'的前提之下，还偏要有'原创癌'" | 技术 + 判决混装 | 有 |
| 1 内部 | "本来想推荐你参考天之火……**但是稍微翻看了一下你的个人主页**，看到你似乎'讨厌男凝'……嗯……就很……" | **举证式人身判决** | 无 |
| 2 | 线稿 / 黑白 / 透视 / Ctrl+U / 雨水"生态位" | **硬技术，正确** | 有 |
| 3 | 色相偏移 / 别琢磨"藏色" | **技术，正确** | 有 |
| 收口 | "这种做梦、**信邪教做祈祷**……一样的幻想，是不可能实现的" | **升维判决** | 无 |

**注意三件事，它们推翻了"前半段讲理、后半段翻脸"这个直觉模型：**

1. **定罪从第一句就存在**，不需要转折点；
2. **技术段与判决段是交错的**，不是前后两大块——**它只有密度变化，没有结构转折**；
3. **最私人的一击藏在编号清单内部**，借"1、2、3"的秩序掩护自己。

**⇒ 判据不能是"找转折句"，只能是：逐条数判断，看哪一条给了你下一步动作。**

## 4. 形态特征清单

### 4.1 为什么它通不过审查（这是它能长期存在的原因）

平台治的是"不友善"：脏话、人身攻击、明显引战。**一代长在射程里，二代不长。**

| | 一代形态特征 | 二代形态特征 |
|---|---|---|
| 标题 | 标题党、绝对化 | 平实问句式，甚至只是复述对方问题 |
| 措辞 | 脏字、对骂 | 专业术语、编号、方括号 |
| 内容 | 空心 | **有真实技术含量** |
| 对象 | 抽象群体 | **具体个人**（但用"顺带"的姿态说） |
| 免责 | "开个玩笑" | "我说难听点""我就明牌""只是顺口提一句" |
| 可处罚性 | **高** | **≈0** |

**结论：平台规则是为一代设计的。二代是从规则盲区里长出来的。**

**实测数据**：一位此类作者的公开档案为 1,890 条回答、7.3 万关注、97,886 次赞同、170 次公共编辑，跨度多年。**其内容在技术上完全合规。**

### 4.2 可识别的五个动作

1. **载体前置**——先给正确、专业、可核实的技术内容；
2. **编号收容**——把人身判决塞进编号清单，借序号秩序通过；
3. **顺带式定罪**——用"稍微翻看了一下""嗯……就很……"这类轻姿态说出最重的话；
4. **举证式杀伤**——**真的去翻对方主页、旧作、公开言论**，拿真实材料当武器（比虚构动机更难反驳，因为材料是真的）；
5. **收口升维**——最后 1–3 句从"你这一张/这一件事"抬到价值与道德层面，从而**免疫反驳**（你无法用一张画证明自己不是"信邪教的人"）。

### 4.3 自毁点：载体是可以分离的

**二代有一个一代没有的致命弱点：它的效力 100% 寄生在"技术判断与资格判决必须被打包接收"这件事上。**

一旦拆开：

- **技术判断**（"黑白必须基于透视"）→ **拿走，能用**
- **资格判决**（"你不配问这个"）→ **扔掉，没有原告**

> **一代只能靠免疫（举报、拉黑、无视）；二代可以靠拆解。**
> **因为一代没有内容可拆，二代有——而它有内容这件事，正是它的死穴。**

---

## 5. 受害人的体验（为什么它特别难恢复）

二代的杀伤不落在"你被骂了"，落在**三件同时发生的事**：

1. **他说的技术部分是对的** → 你没法整体否定；
2. **他对你的判决是不可核对的**（动机、资质、资格）→ 你没法反驳；
3. **它对你的伤害是具体的、指名的、有据的** → 你没法当成抽象的网络噪音。

**结果是：愤怒没有出口，只能向内。**

**已核对的真实反馈**（来自一位反复接触此类文本的读者，原文）：

> "觉得憋、觉得闷。"
> "他这种人让我看着很难受抑郁。"

**与一代的对照：**

> **一代让你生气，二代让你怀疑自己。**
> **怀疑自己难恢复得多，因为它没有出口，也没有结束的时刻。**

## 6. 为什么命名本身会被吸收

二代对这种识别有一个预置回应：

> **"你被批评了，就发明一个词说这是钓鱼？"**

**这正是它的结构**——它不需要辩解，它只需要**把"命名"这个动作变成你承受能力不足的证据。**

所以：

- 一代能被治住，是因为名字后面接了一个动作（举报、拉黑、不转发）；
- **二代只命名是不够的。命名必须接上一个可传授的动作**，否则它会把这个名字也吞掉。

**那个动作是**：拆包裹（§4.3），以及**改变默认预期**（见下）。

---

## 7. 为什么它在此刻出现

三个前提条件在过去十年才同时成熟：

1. **受众的免疫力升级了。** 人们已经能识别一代的标记（标题党、绝对化、脏字），**识别一旦形成，旧形态就失效了**——这是任何"钓法"的必然演化；
2. **平台规则固化了。** 规则永远针对上一代形态，**每一条新规则都在为下一代腾出空间**；
3. **"理性"和"专业"成为这一代最受尊敬的话语形式。** 攻击借用它，就获得了它的信用。

**规律（可检验）：每一代攻击，都借用那个时代最受尊敬的话语形式。**

| 代际 | 借用的话语 | 形态 |
|---|---|---|
| 一代 | **"真性情"** | 我直，我糙，我就是这样 |
| 二代 | **"讲道理 + 专业性"** | 我有依据，这是行业常识，我是为你好 |
| 三代（预测） | **"关心 / 疗愈"** | 你这样的反应，说明你有些东西没处理 |

**三代的预测依据**：它比理性更难反驳——**你可以要求一个人拿出论据，但你没法要求他拿出论据来证明你不缺爱。**

（此条为**推论**，可证伪：若未来主流攻击形态未朝诊断式关心的方向演化，则本预测错误。）

## 8. 识别流程（可操作）

拿到一段让你不适的长文本，按顺序问八个问题：

1. **它有没有真实的技术判断？** 有 → 进入二代嫌疑；无 → 可能只是一代或纯粹的情绪。
2. **这些技术判断，他用在哪了？** 用来给你下一步动作 → 批评；**只用来给后面的判决做抵押 → 二代。**
3. **定罪在哪一句开始？** 不要找转折句——**从第一句开始逐条数。**如果首句就是判决，它没有转折点。
4. **逐条问：这一条给了我可执行的下一步吗？** 给了的留下；只给结论的标红。
5. **人身判决藏在哪里？** 特别注意**编号清单内部**、"顺带"句、括号里。
6. **他有没有核对过可核对的？** 逐条要求链接、要求对齐的说法 → 是批评；**要求不到就上升到动机 → 是二代。**
7. **他有没有真的去查你？** 有 → 举证式杀伤（比虚构动机更难对付，因为材料是真的）。
8. **收口的最后两句，是在谈事还是在谈人？** 谈人 → 那是闭合方式，不是结论。

**最终动作（唯一有效的那个）**：

> **把包裹打开。技术判断拿走，资格判决扔掉。**
> **它需要你整体接收才能运作。你不接收整体，它就不成立。**

---

## 9. 与他人讨论这个框架时要说清的三件事

1. **不要说"他就是个喷子"**——这会让你的判断立刻失去可信度，因为**他的技术部分是真的**；
2. **不要用"你很刻薄"去回应**——**刻薄不是反驳**，而且这一招会被立刻归类为"受不了批评"；
3. **要说的是一句可核对的话**：

> **"他给的所有东西，都在他决定动手之前；动手之后，他给的只有判决。"**

---

## 10. 本框架的边界（Limitations）

- **它不判断作者的意图。** 我们无法知道一个人是"故意钓"还是"真心刻薄"。**本框架不依赖这一点**——因为无论哪种，对受害者的效果一样。
- **它不声称二代比一代"更坏"。** 它只说**作用时间更长、更难反驳、更难过审**。
- **它有误报风险。** 严厉的正常批评同样会让人不适，**甚至同样会夹带情绪化的人身评价**。分界线只有一条：**判断对象是"你的问题"还是"你这个人"。**
- **它不适用于内部反思。** 用于拆解他人文本时它有明确判据；**用于自我审视时会失准**——因为你既是判决者也是被判决者（此时"技术判断 vs 资格判决"的分栏不成立，参见负控样本）。
- **样本偏差。** 本框架的实证部分来自**同一作者的少量文本**（两篇长回答 + 94 条短想法）。**它的普适性尚未被跨作者样本检验。**
